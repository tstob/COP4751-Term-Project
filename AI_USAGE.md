# AI Usage Documentation

## AI Tool Used

I used ChatGPT as a development assistant while working on my Job Application Tracker project.

I mainly used it to help me understand the requirements, develop different parts of the application, troubleshoot errors, reduce the repetitive coding, and verify that the features worked as intended.

## Key Prompts and How I Used AI

### 1. Setting Up Flask and MySQL

**Example prompt:** "Show me an effective connection of my Flask application to my MySQL job_tracker database."

I used ChatGPT to help me understand how Flask connects to MySQL through Python. It assisted with the database connection setup, the project file structure, and troubleshooting connection errors.

I tested the connection locally and worked through issues involving my MySQL password and environment variables.

### 2. Developing CRUD Functionality

**Example prompt:** "Help me implement the functions in my app: add, view, edit, and delete records for the tables."

ChatGPT helped me develop Flask routes, and HTML templates for the four main database tables.


### 3. Implementing Job Match

**Example prompt:** "How can I compare a user's skills with the required skills stored in the jobs table and calculate a match percentage?"

GPT assisted in developing the Job feature using the JSON requirements stored in MySQL.

I tested the feature by entering Python, SQL, and Flask as sample skills. I verified that the application displayed matching jobs, calculated percentages, and identified missing skills.

### 4. Improving the Website's Appearance

**Example prompt:** "Help me improve the website's appearance using CSS without changing the existing functionality. Also generate a color palette of options."

I chose a yellow background, adjusted the heading colors, and added blue to links and underlined. I reviewed the changes in my browser to make sure the website remained readable and easy to navigate.

### 5. Preparing the Project for Submission

**Example prompt:** "Remind me how to pull export from MySQL, the requirements.txt, formats for the README.md, and AI usage documentation for GitHub submission. "

GPT walked me through exporting the database structure and sample data. I had reviewed the SQL exports to confirm that the required tables, relationships, and JSON data were included.

## Modifications and Decisions I Made

Although I used AI generated suggestions, I made decisions about how to apply them to my project, especially when the formatting was too formal looking.

I chose the website's colors and appearance, kept the existing database structure, and tested each feature before moving forward. I used GPT to help me work through errors and made adjustments when it did not work as expected.

For Job Match, I used the existing JSON requirements in the database and tested the results against the skills entered.

## What I Learned

This project helped me better understand how a Flask application communicates with a MySQL database and how SQL queries support the features users interact with in a browser.

I gained more experience working with CRUD operations,  JSON data, Flask routes, HTML templates, and CSS.

I also remembered the importance of testing code rather than assuming that a suggested solution will work immediately. GPT gave me examples of what to test as opposed to switching what I did.

Using ChatGPT helped me work through unfamiliar ground, but I still needed to review the instructions, pull from past class assignments, apply some changes, troubleshoot errors, and verify the results myself.

## Reflection

Chat was useful as a development and troubleshooting resource throughout this project. It really helped me understand the steps involved to break down a error I couldn't figure out.

It gave structure to my code and helped refresh my memory on what I needed to be doing. It gave me assurance. The labs were a helpful starter, but while going through them I didn't realize it would actually build up as it did. So I used GPT to also confirm that what I've been doing is a legit database and application because it was especially important when connecting Flask to MySQL, implementing Job Match, and preparing the project files for submission.
